# 캡처로 노임단가·제비율·자재단가 가져오기

1. **적용 기준 및 설정 → 캡처 기준자료 가져오기**를 엽니다.
2. 자료 종류를 고르고 **AI 요청문 복사**를 누릅니다. 이 요청문과 노임표·제비율표·자재단가표 캡처를 AI에 전달합니다. 현재 프로젝트의 직종명과 제비율 ID가 요청문에 들어 있습니다.
3. AI가 준 JSON을 붙여넣거나 **JSON 파일 열기**로 불러옵니다.
4. 미리보기에서 단가·단위·적용기간·적용 구간·기존 값 변경을 확인하고 필요한 행을 선택합니다. 자료에 없는 출처·기간은 공통 보충 입력란에 실제 근거를 확인해 입력합니다.
5. 확인 체크 후 **선택한 항목 적용**을 누르고 작업 JSON으로 저장합니다.

노임은 같은 직종의 적용기간이 정확히 같은 경우 갱신합니다. 이전 기간의 노임은 남기며 기간이 일부 겹치는 입력은 차단합니다. 시급·월급을 일급으로 자동 환산하지 않습니다. 직종명은 공백 차이만 맞추며 비슷한 이름으로 추측하지 않습니다.

제비율은 **미검토** 상태로 가져옵니다. 공사규모·기간별 후보가 여러 개면 사용할 행을 직접 선택해야 합니다. 가져온 뒤 적용표에서 적용 여부와 산정 기준을 확인하세요. 참조 금액이 없거나 순환 참조인 입력은 적용되지 않습니다.

자재는 품명·규격·단위가 일치하는 기존 주자재·부자재·독립 자재의 단가를 갱신하며 수량은 유지합니다. 새 자재단가는 수량 0의 참고용 행으로 들어갑니다. 실제 수량을 입력하거나 자재 구성에서 사용할 때 공사비에 반영됩니다. 부가세·운반비 등 포함 조건은 출처·비고로 보존하므로 캡처와 함께 확인하세요.

## 다른 작업자가 캡처를 받았을 때

사용자가 이 대화에 캡처를 주면 아래 형식의 JSON 또는 `.json` 파일을 만들어 전달합니다. 금액이나 적용기간을 읽을 수 없으면 추정하지 말고 `null`과 비고를 남깁니다. 노임단가·자재단가는 금액이 불명확한 행을 적용할 수 없고, 제비율은 값이 비어도 미검토 상태로 수동 보완할 수 있습니다. 업무 캡처·변환 결과를 공개 저장소에 넣지 않습니다.

최상위 `format`은 `ict-estimator-basis`, `version`은 `1`입니다. 수량산출용 `ict-estimator-takeoff` 또는 전체 작업 JSON과 혼용하지 않습니다. 목록은 합계 2,000건, 파일은 2MB 이내입니다. 아래 값은 전부 합성 예시입니다.

```json
{
  "format": "ict-estimator-basis",
  "version": 1,
  "source": "시험 자료 1쪽",
  "from": "2026-09-01",
  "to": "2026-12-31",
  "wages": [
    {"trade": "통신케이블공", "price": 123456, "unit": "원/일", "confidence": "high", "note": "합성 예시"}
  ],
  "rates": [
    {"id": "indirect", "name": "간접노무비", "method": "percent", "rate": 3.56, "addition": 0, "bases": ["directLabor"], "condition": "합성 예시 구간", "confidence": "high"}
  ],
  "materials": [
    {"name": "시험 케이블", "spec": "A", "unit": "m", "price": 1000, "date": null, "note": "합성 예시·부가세 별도", "confidence": "high"}
  ],
  "assumptions": []
}
```

- 행의 `source/from/to`가 있으면 최상위보다 우선합니다. 비어 있는 경우에만 공통 입력을 보충합니다.
- `rate`는 퍼센트 숫자입니다. 3.56% → `3.56`. 금액 직접입력은 `method:"fixed"`, `fixedAmount`를 사용합니다.
- `bases`는 `material`(재료비), `directLabor`(직접노무비), `expense`(직접경비), 다른 제비율의 `id`를 사용합니다. 복잡한 원식을 임의 단순화하지 않습니다.
- `confidence:"low"` 등 불확실한 행, 같은 항목의 여러 후보는 기본 선택하지 않습니다. 전체 적용 전 사용자가 캡처와 대조해야 합니다.
- 웹앱은 캡처를 외부로 전송하거나 AI를 호출하지 않습니다. 사용자가 받은 텍스트·파일을 브라우저 메모리에서 처리합니다.
