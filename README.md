# ICT Construction Estimator

2026년 정보통신공사 표준품셈 전체 587쪽의 본문·표·해설·원문 이미지와 제공된 빈내역 양식을 연결한 정적 웹앱입니다. 13개 장의 번호 항목 822개, 추출 표 726개, 계산 후보 4,032개를 수록합니다. 후보의 원문 대조와 조건 검토 후 계산용으로 등록합니다. 전 항목의 규정 해석과 자동계산 검증은 완료되지 않았습니다.

## 실행

압축을 풀고 `index.html`을 Edge 또는 Chrome으로 여세요. 외부 CDN이나 설치 과정 없이 프로젝트 안의 JavaScript를 사용합니다. 이 환경에서는 브라우저 실행이 차단되어 직접 파일 열기 호환성 및 화면 검증을 완료하지 못했습니다. 기관 브라우저가 로컬 파일 스크립트를 제한하면 GitHub Pages의 정적 배포를 사용하거나 승인된 로컬 정적 서버를 이용하세요.

개발용 Node.js 22 이상에서 다음 명령을 사용할 수 있습니다.

```powershell
node --test tests/*.test.cjs
node build.cjs
```

`dist`는 index.html, src, vendor만 복사합니다. 사용자 업무 파일과 저장한 프로젝트 JSON을 해당 폴더에 넣지 마세요. 실행 시 업무 데이터는 메모리에만 존재하며, 새로고침하면 사라집니다. 작업 JSON 저장 버튼으로 PC에 저장할 수 있습니다.

## 업무 순서

첫 화면은 **대시보드**이며, 메뉴는 **대시보드 → 공사정보 관리 → 공사비 산정** 순으로 시작합니다. 공사비 산정에서 공종·규격을 검색하고 수량, 단위당 재료 단가, 할증을 입력합니다. 원문 대조가 필요한 후보는 등록 화면에서 검토를 마치면 공사비 산정 화면으로 돌아옵니다. 저장한 공종과 경비는 복사·수정·삭제할 수 있습니다.

공통 할증은 2026 품셈 1-2-2의 14개 분류를 제공합니다. 공종 해설 계수 × (1 + 공통 품 할증률 합계) × (1 + 노임 할증률 합계)로 노무비를 계산합니다. 야간작업은 품 25%와 노임 50%를 함께 적용하며, 다른 공통 품 할증과는 품 할증끼리 합산합니다. 고소작업 높이·건물층수·왕복 이동시간은 입력값으로 산정하며, 범위가 정해진 할증은 요율과 적용 근거를 직접 입력합니다. 터널 사다리/고소작업, 전차선 차단/운전빈도·구내입환·사다리, 야간 노임 중복 등은 차단합니다. 공종별 해설의 미등록 조건은 근거와 적용 계수를 직접 입력할 수 있습니다. 일부 작업분만 해당되면 수량 행을 나누세요. 선택하지 않으면 할증 없이 저장됩니다.

1-1-6 재료 할증은 재료 수량만 증가시키고 시공수량과 노무비에는 반영하지 않습니다. 철거손실률은 신규 재료 할증과 다른 개념이므로 여기에 합산하지 않습니다. 공통 품의 적용 조건을 원문과 확인한 후 저장하며, 모든 현장 조건의 적용 여부를 자동 판정하지 않습니다.

2026년 **4-3-1 꼬임케이블 포설(m)**을 선택하면 **동시포설 열 수**를 입력할 수 있습니다. 해설 ⑧의 2열 180%, 3열 260%, 4열 340%, 이후 1열당 80% 가산을 적용합니다. 기존 JSON의 열 수 미입력은 1열로 유지됩니다. 수량은 **케이블 총길이** 또는 **1열 경로길이** 중 선택하며, 기준을 바꾸면 기존 입력을 환산해 총길이를 유지합니다. 경로 100m에 4열이면 총길이는 400m, 노무 품은 1열 100m 품의 3.4배입니다. 총길이 400m로 입력하면 노무 품에 3.4÷4=0.85를 적용하며 재료는 400m로 계산합니다. 설치장소 계수와 공통 품·노임 할증은 별도로 반영합니다. 다른 규격·길이·시공 조건은 행을 나누세요. 다른 공종에 같은 동시포설 비율을 일괄 적용하지 않습니다.

**공종 해설 조건**: 2026년 4-3-1 꼬임케이블 포설, 4-3-2 커넥터 및 Jack 접속, 4-3-3 Patch Panel 및 성단 등(인쇄 90~92쪽)의 해설 할증·감 조건을 공사비 산정 화면에서 선택합니다. 기본 등록 6개 항목과 이 절의 후보를 등록한 항목에 행별로 해당 조건만 표시됩니다. 포박(포박실 148%, 케이블 타이 110%), 케이블 형태(8자 115%, 강대 120%, 가요성 금속피 150%), 옥외 자기지지형 120%, 100P 초과 대수(200P 180%…), RS-232C 11Pin 이상 130%, STP·FTP Modular 130%, Outlet 구수(2구 120%…4구 160%, 이후 2구당 20%), Cat6 135%, Outlet Box 6구 130%·12구 325%, 110 Block 동시 세트, 젤리충진 성단 150%, 랙 이동형 20%, 조립 Patch Panel 70%, MDF·랙 동시 설치 열 수, 철거(불용·재사용)를 지원합니다. 동시 설치 세트·열 수는 수량을 전체 대수로 입력하며 1대당 (동시 설치 비율 ÷ 대수)를 적용합니다. 서로 다른 해설 조건은 곱하여 기본 품을 만든 뒤 1-2-2-15에 따라 공통 품 할증을 합산 적용합니다. 곱셈 결합은 사용자 결정(2026-11-12)에 따른 것입니다. 철거 행에는 재료 단가와 재료 할증을 입력할 수 없습니다. 품셈에 같은 해설 번호의 계수가 이미 등록되어 있으면 해당 그룹은 표시하지 않아 중복 적용을 막습니다. 별도 계상 사항(몰딩, 성단, 5-1-1 철가·포박, 안전시설, 회선시험)은 별도 행으로 입력합니다. 다른 장의 공종 해설은 아직 구조화하지 않았으며 추가 배율 직접입력을 사용합니다.

**전체 품셈의 해설 조건 (자동 추출)**: 4-3-1~4-3-3 외의 모든 절은 `tools/extract_commentary.cjs`가 원문 전체 본문에서 각 절의 [해 설] 항목을 추출해 만든 `src/commentary-data.js`를 사용합니다. 555개 절, 해설 3,277개 항목 중 904개 항목의 비율 문구(“본 품셈의 N% 적용”, “N% 가산”, “N% 감”, 쉼표로 나열된 규격별 비율, 철거 불용·재사용, 2열 180%·3열 260%·4열 340% 동시 설치)를 선택지로 바꿨습니다. 공사비 산정 화면에는 각 조건의 원문 문장과 원문 쪽 링크가 함께 표시되며, 해당 행의 규격·공정에 맞는지 확인한 뒤 선택합니다. 다음 문구는 자동 계수로 만들지 않고 “그 밖의 해설”에 표시하므로 추가 배율 직접입력을 사용하세요: 다른 규격을 기준으로 한 비율(예: 100P의 180%, 6구 품셈의 250%), 단위당·마다 증분(1대당 80% 가산, 3m마다 5% 가산), 상한 문구(N%까지), 범위(70~80%), 100% 이상 “할증” 문구, 1-2-2 공통 할증 참조(공통 할증 화면에서 선택). 자동 추출은 PDF 줄바꿈과 문장 해석의 한계가 있어 검증 완료 데이터가 아닙니다. 원문이 바뀌면 `node tools/extract_commentary.cjs`로 다시 생성합니다.

**적용 기준 및 설정 → 제비율 적용표**의 **첨부 서식의 17개 항목 불러오기**는 2026.04.13. 건축공사 간접공사비 서식의 항목·산정 기준·유의사항을 불러옵니다. 요율은 비워 두며 사용자가 적용/제외를 선택하고 입력합니다. 요율 방식은 기준금액 × 요율 + 기초액(원), 금액 직접입력 방식은 최종 산정금액을 사용합니다. 관급 포함 안전관리비의 두 산식 비교, 공기(년)를 적용하는 이행보증수수료 등은 계산 근거와 최종 금액을 직접 입력합니다. 통신공사에 대한 별도 일반관리비 구분, 환경보전비 및 건설기계대여보증의 적용 제외를 확인하세요. 이 서식의 요율을 모든 통신공사에 자동 적용하지 않습니다. 적용표 저장 후 작업 JSON으로 보관합니다.

기계경비는 사용시간과 시간당 단가를 곱하고, 기타경비는 입력 금액을 합산합니다. 노임단가와 제비율을 등록한 뒤 **산정하기**를 누르면 원가계산서를 확인할 수 있습니다. **엑셀 저장**은 설계내역서 통합문서를 만듭니다. 시트는 표지, 원가계산서, 집계표, 설계내역서, 일위대가표, 물량산출근거, 인건비산출기초, 자재단가산출기초입니다(`src/design-xlsx.js`).
- 시트끼리 수식으로 연결됩니다. 물량산출근거의 수량, 자재단가산출기초의 단가, 인건비산출기초의 노임을 바꾸면 Excel에서 일위대가표 공량 → 설계내역서 직종별 노무비 → 집계표 → 원가계산서 → 표지 공사금액이 다시 계산됩니다.
- 일위대가표 품셈 칸은 `기본품*계수` 수식으로 공종 해설·공통 할증 계수를 보여 줍니다. 행별 노임 할증(야간 50% 등)은 직종별 노임을 하나로 쓰기 위해 계수에 포함하고 비고에 표시합니다.
- 원가계산서는 제비율 이름으로 위치를 정합니다: 간접재료비 → 재료비, 간접노무비 → 노무비, 일반관리비·이윤 → 순공사원가 다음, 부가가치세 → 총원가 다음, 그 밖의 항목 → 경비. 산출 근거는 (A)·(B)·(C)·(D) 기호로 줄여 씁니다.
- "합계"는 앱 계산 총액과 같고, "총 금 액"은 천원 미만을 절사합니다.
- 표지 공사금액의 한글 금액은 Excel의 NUMBERSTRING 함수를 사용하므로 LibreOffice 등에서는 숫자만 표시됩니다.
- 표지 공사개요는 공사정보의 "공사개요"(항목은 ;로 구분)를 사용하고, 비어 있으면 공종명을 나열합니다.

**공사원가계산 화면**은 엑셀 저장과 같은 시트를 탭으로 바로 보여 줍니다(원가계산서·집계표·설계내역서·일위대가표 등). 금액 칸에 마우스를 올리면 엑셀 수식이 보입니다.

**자재 구성**: 공사비 산정의 각 공종에 주자재와 부자재를 함께 넣습니다. 부자재 수량은 "작업 1단위당 수량"으로 시공수량에 따라 계산됩니다(예: 패치코드 1개 = UTP 케이블 3m + 랜 커넥터 2개 + 보호캡 2개). 전선관에는 3-1-2 부속품률(주자재 금액 × 20%, CD·PF관 40%) 줄을 넣을 수 있습니다. 공종을 고르면 추천 구성이 자동으로 들어가며, 같은 공사에서 입력한 같은 품명·규격 단가를 재사용합니다. 단가가 빈 자재가 있으면 엑셀 저장 전에 알려 줍니다. 엑셀에서는 부자재 수량과 부속품률이 수식으로 연결됩니다.

**도면 물량 가져오기 (Claude·ChatGPT)**: 공사비 산정 맨 위에서 "AI 요청문 복사"를 누르고, 도면(PDF·이미지)과 함께 Claude나 ChatGPT에 붙여 넣습니다. AI가 준 JSON 답변을 붙여 넣고 미리보기를 누르면 등록 품셈과 자동으로 연결되고, 선택한 항목이 수량 행으로 들어갑니다. 사이트는 외부에 접속하지 않으며, 추가된 행은 "확인 필요" 상태라 확인 체크 후에만 엑셀로 저장됩니다. 등록되지 않은 공종은 "품셈 등록 필요"로 표시됩니다.

**정보콘센트 포트 수 산정**: 4-3-2 Modular(Outlet)의 노무 수량은 포트 수(콘센트 개수 × 구수)로 세고, 구수 할증(2구 120%…)을 곱합니다. 예: 6구 2개 → 12포트 × 0.028인 × 180%. 재료비는 콘센트 개수 기준입니다.

**총공사금액 천원 미만 절사**: 앱과 엑셀 모두 총공사금액은 천원 미만을 절사하고, 절사 전 금액을 함께 표시합니다.

**노임 적용기간 일괄 수정**: 노임·제비율 설정에서 노임을 골라 적용기간을 한 번에 바꿉니다(상반기·하반기·연간 버튼, 기준일 밖 노임 자동 선택). 단가는 그대로이고 출처에 이전 기간을 남깁니다. 같은 직종 기간이 겹치면 거부합니다.

**노무비 자동 계산**: 노임단가를 등록하면 공사비 산정에서 바로 노무비가 계산됩니다. "품셈·적용 조건 확인" 체크 전에도 금액은 표시되고, 확인 필요 항목으로만 남아 엑셀 저장을 막습니다. 공사 기준일이 노임 적용기간 밖이면 가장 가까운 기간의 노임으로 임시 계산하고 확인 항목에 표시합니다. 같은 직종에 기준일이 겹치는 노임이 2건 이상이거나 출처가 없거나 노임이 없으면 직종별로 한 번 알려 줍니다.

편집을 이어갈 때는 작업 JSON을 사용합니다.

제공된 빈 설계내역서 양식으로 작성하는 순서는 다음과 같습니다. 기계·기타경비가 포함된 작업은 공사원가계산 화면의 **엑셀 저장**을 사용하세요.

1. 공사정보에서 공사명, 위치, 기준일, 연도, 기간, 종류, 발주기관을 입력합니다.
2. Excel 가져오기에서 제공된 빈 설계내역서 양식을 선택합니다. 원본 파일 자체는 프로그램 배포물에 포함되지 않습니다.
3. 노임단가 가져오기에서 같은 양식 또는 동일 구조의 파일을 선택합니다. 기본 가져오기 기간은 원본에 기재된 2026-01-01부터 2026-08-31입니다. 설정에서 실제 적용기간과 근거를 확인합니다. 현재 시점 공사에 그대로 적용하면 안 됩니다.
4. 품셈 검색에서 항목을 추가합니다. 수량산출에서 단위수량과 개수를 입력합니다. 길이가 없는 공종은 단위수량을 1로 두고 개수를 입력합니다. 포설과 성단은 각각 추가합니다.
5. 공종별 해설과 공통 할증을 확인합니다. 공사비 산정에서 선택한 할증의 근거·품 계수·노임 계수를 검토합니다. 변경 이력과 선택값은 작업 JSON에 포함됩니다. 행별 노임 할증을 사용하는 경우 기존 빈 양식 대신 공사원가계산 화면의 엑셀 저장을 사용합니다.
6. 자재를 직접 입력하거나 자재단가산출기초 시트에서 가져옵니다. 여러 셀의 탭 구분 붙여넣기를 지원합니다. 단가·수량 변경은 즉시 계산에 반영됩니다.
7. **노임·제비율 설정**에서 직종별 일 노임과 제비율을 직접 입력합니다. 제비율은 산정 기준 금액, 적용기간, 근거, 적용 여부를 지정합니다. 기존 빈내역서 양식에 내보낼 때는 출력 셀도 지정합니다. 공사금액·기간·종류·기관에 대한 법적 적용 요건은 담당자가 검토합니다. 검토 완료를 선택한 빈 목록은 모든 제비율 제외를 뜻합니다.
8. 일위대가와 공사원가를 확인한 후 Excel 파일을 저장합니다. 수식 변경 이력도 별도 저장합니다. Excel에서 링크 업데이트 여부를 검토한 다음 수량 변경 및 재계산을 확인합니다.

## 데이터 모델과 기준 연결

`src/catalog-data.js`는 전체 문서와 4,032개 계산 후보를 제공합니다. `src/reference`에는 원문 587쪽의 이미지가 있습니다. `src/standards.js`는 기존에 대조한 6개 계산항목을 기본 제공합니다. `src/standards-verified.js`는 3장 배관공사·4장 통신케이블공사 전체 779개 항목을 원문 페이지 이미지와 한 행씩 대조해 등록한 것입니다(2026-11-12). 텍스트로 추출되지 않던 표(3-2-2, 3-3-2, 3-4-2 등)와 자동 후보가 잘못 읽은 표(3-6-1 건축목공 누락 등)도 원문 기준으로 입력했습니다. 원본 PDF의 인쇄면 90~92쪽, PDF 120~122쪽을 텍스트와 렌더링 이미지로 대조했습니다. UTP 구내 4P, RJ45 플러그, Modular Outlet, 2.2m 미만 랙, 24포트 패치패널, 패치패널 성단을 포함합니다. 원문 전체 해설의 기계적 판정을 구현한 것은 아니므로 적용 조건을 확인해야 합니다.

각 품셈은 id, code, name, spec, unit, baseQuantity, labor, year, version, source, page, verified, conditions, included, excluded, separate, revised, adjustments를 가집니다. labor는 직종별 base이며 adjustments는 id, name, factor, basis입니다. 기본 계수는 base입니다. 실제 자료 검증이 완료된 항목만 verified를 true로 설정합니다. 여러 조건의 동시 적용은 검증된 단일 조합 항목으로 사전에 구조화해야 합니다. 프로그램은 임의 계수 합산을 수행하지 않습니다.

노임단가 객체는 trade, price, from, to, source를 갖습니다. 적용일에 해당하는 동일 직종 자료가 0개 또는 2개 이상이면 계산을 막습니다. 자재 객체는 name, spec, unit, price, quantity, date, source, note를 가집니다.

제비율 객체 예시는 다음과 같습니다. 숫자는 등록 형식을 설명하는 0이며 공식 요율이 아닙니다.

```json
{"id":"indirect","name":"간접노무비","rate":0,"bases":["directLabor"],"from":"2026-01-01","to":"2026-12-31","source":"공식 자료명·조항·페이지","reviewed":false,"enabled":false,"cell":"D9"}
```

산정 기준 ID는 material, directLabor, expense와 앞서 등록한 항목 id입니다. expense는 입력한 기계경비와 기타경비의 합계입니다. 요율 계산은 나열 순서대로 수행합니다. 정액, 구간별 누진, 상한액, 역산을 사용하는 항목은 현재 엔진에서 지원하지 않습니다.

표준품셈·노임단가·제비율은 작업 JSON 또는 설정의 JSON 편집으로 등록할 수 있습니다. 다른 기준연도는 year/version과 적용기간을 함께 관리하세요. 자동 PDF 표 추출·검수 편집기와 범용 Excel 열 매핑은 후속 작업입니다.

## Excel 처리

자체 포함한 JSZip 3.x가 ZIP을 읽고 저장합니다. XML 읽기는 브라우저 DOMParser, 쓰기는 지정된 셀 노드 교체를 사용합니다. 전체 통합문서를 다른 객체 모델로 재작성하지 않습니다. 대상 셀 외의 XML 및 ZIP 구성요소는 보존합니다. 바뀐 수식의 캐시값을 제거하고 열기 시 전체 재계산을 요청합니다. 브라우저 자체에는 Excel 전체 수식 평가기가 없습니다.

제공 빈 양식 전용으로 재료비 9행, 직종 7행, 공종 19행을 지원합니다. 초과하면 내보내기를 중단합니다. UPS 전기공사 예시는 시트 구조를 조사했으며 정보통신공사 산정 기준으로 전용하지 않았습니다. 해당 양식의 자동작성과 실제 UPS 금액 대조는 미구현입니다.

원본에 포함된 외부 파일 관계 2개는 보존합니다. 앱에서 링크를 열거나 요청하지 않습니다. Excel이 별도로 링크 갱신을 요청할 수 있으므로 대상을 검토하세요. 매크로, 임베디드 개체, 전자서명 파일은 거부합니다. 배열·데이터표 수식의 직접 수정은 거부하고 공유 수식 기준 셀의 잔존 여부를 검사합니다.

집계표 A5와 자재단가산출기초 A2의 원본 #REF!를 수정합니다. 재료비·직종별 노무비에 원 단위 절사 또는 반올림을 적용합니다. 원가계산서의 기존 고정 제비율은 검토한 목록으로 교체하며, 제외 항목은 0으로 표시합니다. D26의 천원 단위 절사는 원 단위 합계로 바꿉니다. 기존 양식에 있던 법정 요율은 공식 기준으로 자동 채택하지 않습니다. 변경된 수식 및 이유는 JSON 이력으로 제공합니다.

## 전체 품셈 검색과 계산 등록

공종 및 품셈 검색에서 번호·공종·규격·본문을 검색하고 장별로 좁힐 수 있습니다. 페이지당 40개 항목을 표시합니다. 전체 원문·부록 보기와 PDF 쪽 번호 입력으로 1~587쪽을 모두 열 수 있습니다. 본문 검색 결과에는 목차 밖의 부록도 포함됩니다. 이미지 선택 시 확대하며 인터넷 요청 없이 함께 배포한 정적 이미지를 표시합니다.

목차 항목 수에는 상위 분류, 공통기준, 삭제 항목 26개가 포함됩니다. 이를 계산 가능한 규격 수로 해석하지 마세요. 표 726개에는 부록과 설명용 표도 포함됩니다.

계산 후보 4,032개 중 2,464개는 표의 단위 열까지 추출했고, 1,568개는 단위와 기준수량을 원문에서 확인해 입력해야 합니다. 병합 셀의 물리적 위치로 항목명을 이어 붙이고 여러 줄의 숫자를 분리했습니다. 행렬형 표, 식으로 정의된 품은 원문을 검토해 별도 입력해야 합니다. 공통 할증은 공사비 산정 화면에서 조건을 직접 선택합니다.

후보의 원문 대조·등록 버튼으로 편집 화면을 엽니다. 규격, 수량 단위, 기준수량, 직종별 기본품, 적용 조건을 확인하고 확인란을 선택하면 계산용으로 등록됩니다. 확인 전에는 계산 엔진에서 적용을 거부합니다. 등록 후 수량에 추가하고 필요한 직종별 노임을 등록합니다. 자동 후보가 없는 항목도 원문에서 계산항목 등록 버튼으로 입력할 수 있습니다. 삭제 항목에는 등록 버튼이 없습니다.

등록에는 사용자 검토 상태, 검토 시각, 원본 PDF SHA-256, 원문 페이지와 표 위치를 남깁니다. 등록 결과는 작업 JSON에 저장되므로 다음 사용 시 해당 JSON을 열어야 합니다. 원본 이미지와 본문은 프로그램 안에 고정 데이터로 포함됩니다. 업무 공사명이나 수량은 이미지 경로에 포함되지 않습니다.

## 데이터 재생성

`tools`에 PDF 추출·병합셀 복원·목차 및 계산 후보 생성 스크립트를 포함했습니다. Python의 pdfplumber가 필요합니다. 이 스크립트는 제공된 2026판의 PDF 587쪽과 인쇄면 오프셋 30쪽을 대상으로 합니다. 다른 연도에는 페이지·목차 체계를 확인한 후 스크립트와 검증 기준을 수정해야 합니다.

## 잡재료·소모재료 및 제어케이블 해설

공사비 산정 또는 자재단가 관리에서 **잡재료 및 소모재료 · 1-1-12**를 펼칩니다. 소액 소모품을 품목별로 계상하기 어려운 경우에만 사용하고, 전선·케이블·배관자재를 개별 선택한 뒤 2~5%와 적용 사유를 입력합니다. 장비·랙 등은 선택하지 않으며 부속품률은 기준금액에서 제외합니다. 별도 계상한 자재와 중복되지 않는지 확인해야 Excel을 저장할 수 있습니다. 기존 작업은 기본 미적용입니다.

Excel 자재단가산출기초의 1-1-12 적용률과 선택된 재료의 수량·단가를 변경하면 잡재료, 제비율, 총액이 재계산됩니다.

제어케이블 4-4-1 해설은 인쇄 93쪽 원문을 대조했습니다. 동시포설 수량에는 케이블 총길이를 넣습니다. 예: 경로 100m의 4열이면 수량 400m, 노무 계수는 340% ÷ 4 = 0.85입니다. 기존 JSON의 해설 선택값은 유지됩니다.

전원케이블 4-6-1~4-6-3 해설은 인쇄 95~97쪽(PDF 125~127쪽) 원문을 대조해 수작업 규칙으로 옮겼습니다. 자동 추출에서 빠졌던 4-6-1 ② 직매 80%, ⑥ 증설·이설 150%, ⑮ 재활용 철거 90%, 4-6-2 ① 증설·이설 Y·T접속 150%, ② 재배치 170%, 4-6-3 ③ 증설·이설 150%를 선택할 수 있습니다. 심수(④ 2심 140% … 7심 440%)는 기본 단심 기준이며, 전압 할증(⑧ 20%·50% 가산)도 다른 해설 조건과 곱해 적용합니다. 해석이 들어간 부분은 다음과 같습니다. 4-6-1 ⑬ 철거 케이블 다시 감기(40%)는 신규 재료가 없는 작업으로 보아 철거와 같이 재료 단가를 막습니다. ⑬과 ⑮, ⑥ 증설·이설과 ⑬·⑮, 4-6-2 ① 증설·이설과 ② 철거·재배치, 4-6-3 ② 압착단자 30%(신설에 한함)와 ③ 증설·이설은 같은 작업을 두 번 반영하므로 한 행에서 함께 선택할 수 없습니다. 4-6-2 재배치 170%는 철거로 보지 않습니다. 기존 JSON의 해설 선택값(id)은 유지됩니다.

전선관 3-1-1, 광섬유케이블 4-1-1, 동축케이블 4-2-1, 누설동축 4-5-1 해설도 원문 이미지(PDF 91·109~110·118·124쪽)와 대조해 수작업 규칙으로 옮겼습니다. 행(관 종류·포설 방식)에 해당하는 조건만 표시합니다. 예: 3-1-1 CD·PF관 80%는 합성수지 전선관 행, 지중 매설 70%는 후강·합성수지 행, 4-1-1 자기지지형·이설은 가공 행, 8자 포설은 인력견인 행에만 나옵니다. 원문이 직종을 지정한 비율은 해당 직종에만 곱합니다. 4-1-1 ⑩ 8자 포설은 보통인부만 115%, ⑫ 공기압력 양방향 포설은 광케이블설치사 128%·통신외선공 123%·특별인부 131%입니다. 설계내역서 Excel의 일위대가표 품셈 수식도 직종별로 다릅니다. 이 조건이 있는 작업은 기존 빈 양식 내보내기를 쓸 수 없습니다. 보완한 내용은 다음과 같습니다. 3-1-1 ② 콘크리트 노출·블록칸막이 벽 내 120%(누락), 4-2-1 ⑤ 가공케이블 이설은 가공설치품(지하관로 120%)의 70%이므로 84%(자동 추출은 70%), 철거 재활용 90%(누락). 해석이 들어간 부분은 다음과 같습니다. 4-5-1 ② 포설 체감은 케이블 1가닥의 포설 연장이 속한 구간 적용률 하나를 그 가닥 전체에 적용합니다(사용자 결정, 2026-11-13). 예: 800m 1가닥 → 70%. 300m·200m·300m 3가닥은 행을 나눠 각각 100%로 계산한 뒤 합산합니다. 4-1-1 ⑮ 슬림형 내관은 2조 이하 기준에 3조부터 1조당 80%를 더합니다(3조 180%). 4-5-1 ④ 2선 동시는 수량을 경로길이로 넣으면 180%, 케이블 총길이로 넣으면 90%를 선택합니다. 4-2-1 ⑥ 인입선 조당 48%는 단위가 달라 추가 배율로 입력합니다.

광섬유케이블 접속·성단·구내 광 등 4-1-2-1, 4-1-2-2, 4-1-3, 4-1-4, 4-1-6, 4-1-7 해설도 원문 이미지(PDF 111~115·117쪽)와 대조해 수작업 규칙으로 옮겼습니다. 바로잡은 내용은 다음과 같습니다. 4-1-3 ① 기축·리모델링은 광섬유케이블 포설 행 200%, 성단·시험 행 130%입니다(자동 추출은 모든 행 130%). 4-1-4 ② 8자포설은 보통인부에만 15%를 가산합니다. 빠졌던 선택지도 추가했습니다: 4-1-3 ② 36코어 120%, ⑤ 공압 양방향 119%, ⑬ 슬림형 내관 조 수, 4-1-2-1 ④ 분기 수(분기마다 30% 가산), 4-1-2-2 ① 기존 함에 저장함 설치 30%, ③ 동일장소 설치 수, ⑥ IJP Box 분기 수, ⑨ 광분배기 분배 수(8분배 160%, 이후 4분배당 60% 가산). 해석이 들어간 부분은 다음과 같습니다. 4-1-2-2 ③ "2개 180%, 3개 초과 1개당 80% 가산"은 3개 260%로 이어지는 수열로 보았습니다. 4-1-2-1 ④ 해체·조립 70%와 분기 가산을 함께 고르면 곱합니다. 4-1-5 OPGW 해설은 아직 자동 추출입니다.

시내케이블 4-7-1~4-7-6(9개 절) 해설도 원문 이미지(PDF 128~134쪽)와 대조해 수작업 규칙으로 옮겼습니다. 4-7-1은 규격의 지중·가공 구분에 따라 조건을 표시합니다. 가공 행에만 처짐 조정 20%, 라싱와이어 110%, 기설선 상위 120%, 이설 70%가 나오고, 지중 행에만 통신구·동도 115%가 나옵니다. 바로잡은 내용은 다음과 같습니다. 4-7-1 ⑩ 통신구·동도 115%(자동 추출은 계수 1), 4-7-4 ③ 예비심선 절체는 통신케이블공만 65%(자동 추출은 계수 1), 4-7-3 ⑩ 심선 0.5㎜ 110%(누락), 4-7-4-1 ⑤ T·Y 분기 130%(누락). 4-7-5-3 ⑤ 분기 수와 4-7-6 ⑤ 외피탈피 추가 횟수는 입력하면 계산합니다. 간이시험·선번기입·격벽처럼 품이 따로 정해진 가산은 별도 행으로 입력합니다.

자재 추천에는 보호캡 포함 커넥터와 플레이트 별도·포함 콘센트 선택지가 있습니다. 실제 견적·설계 구성에 맞게 선택하세요. 기존 추천 기본값은 유지하며 회사별 구성으로 확정한 것은 아닙니다.

## 캡처 기준자료 가져오기

**적용 기준 및 설정 → 캡처 기준자료 가져오기**에서 노임단가·제비율·자재단가 캡처의 AI 판독 결과를 등록합니다. 요청문을 복사해 캡처와 함께 전달하고, 받은 JSON을 붙여넣거나 파일로 열어 미리보기 → 선택 → 확인 → 적용합니다. 같은 직종·기간의 노임은 갱신하고 제비율은 미검토 상태로 가져옵니다. 자재단가 갱신 시 기존 수량은 유지하며 새 단가 자료는 수량 0으로 등록합니다.

자세한 사용법과 JSON 형식은 [캡처 기준자료 가져오기 안내](docs/BASIS-IMPORT.md)를 참고하세요. 캡처는 웹앱에서 AI로 전송되지 않습니다.
